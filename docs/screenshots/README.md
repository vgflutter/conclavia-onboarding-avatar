# Schermata dello Studio

[Desktop](integration-studio-demo.png) e [mobile](integration-studio-demo-mobile.png) mostrano la vera interfaccia della scheda Integrazione con dati sintetici, creata dal test browser `integration preferences persist`. Nome «Umatt · ambiente dimostrativo», dominio `demo.example`, nessun cliente reale o chiave. Il solo indicatore del server di sviluppo è nascosto durante la cattura.

La schermata documenta la configurazione, non un’integrazione Umatt già collaudata. Per usarla nel sito pubblico mantenere l’indicazione di ambiente dimostrativo. Rigenerare con Playwright e copiare l’artefatto da `test-results` dopo aver controllato il contenuto.
